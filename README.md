# T2 31-DOF Revo2Hand robot model

This repository contains the robot description supplied for the research project:

- `T2_31dof_Revo2Hand.urdf` — URDF robot description
- `T2_31dof_Revo2Hand.xml` — MuJoCo model
- `meshes/` — STL geometry referenced by both descriptions

The archive was unpacked without its macOS `__MACOSX` metadata files. Both XML descriptions parse, and every referenced mesh is present. The model has not yet been tested in Isaac Sim or on a physical robot.
